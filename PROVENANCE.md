# Skill Provenance Index

Every skill in this repository must include `references/provenance.md`.

The provenance file answers four questions:

1. Which primary sources support technical claims?
2. Which external skill/framework ideas influenced the design?
3. What workflow or judgment was independently synthesized for this library?
4. Was third-party skill text copied? The repository policy is **no wholesale copying**.

This is intentionally different from `RESEARCH.md`:

- `RESEARCH.md` records repository-wide standards and fast-moving research areas.
- each `references/provenance.md` records the origin of one skill.

## Contribution rule

A new skill is incomplete until its provenance file exists. When adapting a useful idea from another public skill, describe the principle and source here, then write an original implementation appropriate to this library rather than copying the source text.
