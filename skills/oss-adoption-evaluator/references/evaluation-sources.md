# Evaluation Sources

Checked: 2026-10-04.

Useful primary/reference sources:

- OpenSSF Scorecard: https://openssf.org/projects/scorecard/
- SPDX license list/specification: https://spdx.org/licenses/
- Repository release history, license files, security policy, dependency manifests, and upstream source remain primary evidence.

OpenSSF Scorecard can surface automated security-practice signals, but its score is not a production-readiness verdict. Combine it with source inspection, maintenance history, architecture fit, and a representative proof of concept.

For licensing, record uncertainty explicitly when the integration/distribution model changes the answer.
