# Visual Quality Rubric

Use this when a simple review is not enough.

## Concept fidelity

Ask whether the same design thesis is visible without explaining it. If the reference is layered, tactile, technical, editorial, playful, or architectural, the implementation should communicate that through the full composition rather than a few borrowed colors.

## Depth

Depth can come from:

- geometric layering and occlusion;
- bevel/edge treatment;
- normal or bump response;
- roughness/specular variation;
- cast/contact shadows;
- parallax/DoF where the platform supports it;
- foreground/background scale separation;
- atmospheric contrast.

More effects are not automatically more depth. Effects must agree on a light/material model.

## Typography

Typography is part of geometry. Review bounding boxes, line length, baseline relationships, tracking, weight distribution, and negative space. Decorative assets must not compete with critical numbers or labels.

## Small displays

For watch faces, launchers, dashboards, and compact UIs, review from the intended viewing distance. A detail that only works zoomed-in does not count as useful hierarchy.

## Evidence output

A strong review produces:

1. pass/fail on concept fidelity;
2. P0/P1/P2 issues;
3. exact implementation changes;
4. a new rendered comparison;
5. remaining gaps.
